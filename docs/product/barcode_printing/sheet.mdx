# Sheet (A4) Printing

Use **Sheet printing** to print many barcode labels on a normal **A4 sheet** with a laser or inkjet printer. This is the right choice when you use pre-cut A4 label sheets.

> This option must be configured by the support team. See [Barcode Printing](/product/barcode_printing/overview).

---

## Print Labels

1. Go to **Product Management** → **Product** → **Material Master** and open the item.
2. Open the **More Codes** tab and click **Print Barcode**.

   <Image src="/images/barcode_more_codes.png" alt="Print Barcode button in the More Codes tab" zoom={true} />

3. The **Laser Barcode Printing** window opens.

<Image src="/images/barcode_sheet.png" alt="Laser Barcode Printing window" zoom={true} />

4. Set the **Start Position** (see below).
5. Under **Select Items**, tick the item and enter the **Qty**.
6. Click **Preview** to see the A4 sheet layout.
7. Click **Print**. The browser print window opens. Select the correct printer and print.

| Field | Description |
| ----- | ----------- |
| **Start Position** | The row on the sheet where printing should begin |
| **Select Items** | The items to print. Use **Select All** or **Clear All** to tick or untick every item |
| **Qty** | Number of labels to print for each item |
| **Preview** | Shows the labels laid out on the A4 sheet |
| **Print** | Opens the browser print window |

---

## Start Position

The start position lets you reuse a sheet that has already been partly printed.

| Start Position | Printing begins at |
| -------------- | ------------------ |
| `1` | The **first row** of the sheet |
| `10` | The **10th row** of the sheet |

> If part of the sheet was used earlier, enter the first free row so new labels do not print over used labels.

---

## Notes

> - Printing opens the browser print dialog. Choose the correct printer before clicking **Print**.
> - The preview shows how labels fit on one A4 page. A large quantity continues onto the next page.
