# Zebra (ZPL) Printing

Use **Zebra printing** with label printers that support **ZPL** (Zebra Programming Language). Labels are sent straight to the printer through its driver, so no browser print dialog appears.

> This option must be configured by the support team. See [Barcode Printing](/product/barcode_printing/overview).

---

## Open the Barcode Printing Window

You can open the printing window from a product or from a document.

**From a product**

1. Go to **Product Management** → **Product** → **Material Master** and open the item.
2. Open the **More Codes** tab.
3. Click **Print Barcode**.

<Image src="/images/barcode_more_codes.png" alt="Print Barcode button in the More Codes tab" zoom={true} />

**From a document**

Zebra printing is also available in **GRN**, **PR** and **Sales**. Open the document and use the barcode print option to label the items on it.

---

## Print Labels

The **Barcode Printing** window opens.

<Image src="/images/barcode_zebra_popup.png" alt="Barcode Printing window for Zebra printing" zoom={true} />

1. **Template**: Search for and select the label template.
2. **Select Items**: Tick the items you want to print. Enter the **Qty** for each item.
3. Click **Preview** to see how the label will look.
4. Click **Print** to send the labels to the printer.

<Image src="/images/barcode_zebra_preview.png" alt="Barcode label preview" zoom={true} />

| Field | Description |
| ----- | ----------- |
| **Template** | The label layout. Search and pick from the templates available for your account |
| **Select Items** | The items to print. The item you opened from is already selected |
| **Qty** | Number of labels to print for that item. A quantity of `5` prints the label 5 times |
| **Preview** | Shows the label as it will be printed |
| **Print** | Prints directly to the printer through its driver |

---

## Templates

Two kinds of template are normally available:

- **Item Label** – the label stuck on each product.
- **Shelf Label** – the label placed on the shelf.

The layout of each template (size, fields, position of the barcode and price) can be customised. Ask the support team if you need a new label design or changes to an existing one.

---

## Notes

> - Printing goes directly to the printer through its driver. Make sure the Zebra printer is installed and set as available on the computer you are using.
> - Quantity prints the same label that many times.
> - If the preview looks correct but nothing prints, check the printer driver and cable, then contact support.
