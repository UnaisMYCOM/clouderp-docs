# Goods Received Note (GRN)

A **Goods Received Note (GRN)** records goods that have arrived from a supplier. A GRN can be created directly, or by converting a [Purchase Order](/purchase/purchase_order) fully or partially.

---

## Document Flow

```text
Purchase Order  →  Goods Received Note (GRN)  →  Purchase Return
```

---

## GRN List

Go to **Purchase Management** → **Goods Received Note**. The main screen lists every GRN.

| Control | Description |

## Create a GRN

You can create a GRN in two ways:

| Method | Description |
| ------ | ----------- |
| **From a Purchase Order** | Open the purchase order and click **Convert to GRN**. You can convert fully or partially. See [Convert to GRN](/purchase/purchase_order#convert-to-grn) |
| **Directly** | Click **Create Goods Received Note** on the GRN list and enter the supplier and items |

## GRN Screen

<Image src="/images/grn_edit.png" alt="Goods Received Note" zoom={true} />

The top of a saved GRN shows its number (for example `GRN-2026-09-000620`) and who created and last updated it. Click **Hide** to collapse the header section and see more of the item list.

### Header Section

Fields marked with **\*** are mandatory. Fields marked *non editable* cannot be changed after the GRN is saved.

| Field | Description |
| ----- | ----------- |
| **GRN Date \*** | The date the goods were received. Non editable |
| **Delivery Date \*** | The date the goods were delivered. This one can be changed |
| **Location \*** | The location (branch) receiving the goods. Non editable |
| **Sub Location Code \*** | The sub location the stock goes into, for example `001 - Sales`. Non editable |
| **Division Code \*** | The division, for example `001 - SALE`. Non editable |
| **Supplier Invoice Number** | The supplier's invoice number for this delivery. Non editable |
| **Purchase Order** | The purchase order this GRN was created from. Filled in automatically when you convert a PO. Non editable |
| **Supplier Code \*** | The supplier. Non editable |
| **Supplier Name** | Filled in automatically from the supplier. Non editable |
| **Payment Type \*** | How the purchase is paid, for example `credit` |
| **GRN Type \*** | The type of GRN, for example `Normal` |
| **Purchase Type \*** | `Local` or `International` |
| **Discount Type** | The kind of discount, for example `Invoice Discount (%)`. Non editable |
| **Currency \*** | The currency of the GRN, for example `LKR` |
| **Discount % \*** | A percentage discount applied to the whole GRN. Enter `0` for no discount |
| **Agreement Discount %** | The discount from the supplier's agreement. Filled in automatically. Non editable |
| **Remarks** | Any free-text notes |
| **No Tax** | Tick this to create the GRN without tax |

### Products Tab

Items are added the same way on every document: **Upload Products** (CSV file), **Quick Add Items** or **Add**. See [Adding Items to the Invoice](/sales/sales_entry/sales_invoice#adding-items-to-the-invoice).

| Column | Description |
| ------ | ----------- |
| **Line Number** | Line number of the item |
| **Code** | Product code |
| **Description** | Name of the product |
| **Last Net Cost** | The net cost of the item on the previous purchase |
| **UOM Code** | The unit of measure the item is received in |
| **Quantity** | Quantity received |
| **MRP** | Maximum retail price |
| **Unit Price** | Purchase price per unit |
| **Margin %** | The profit margin of the item, calculated from the **MRP** and the **unit cost** (Unit Price). See [Margin %](#margin-) |
| **Total Amount** | Amount before discount and tax |
| **Tax Amount** | Tax for the line |
| **Discount amount** | Discount for the line |
| **Net Amount** | Final amount for the line |

Each line has a **pencil icon** to edit it, a **delete icon** to remove it and a **three-dot menu** for more options.

#### Margin %

**Margin %** is worked out for each line from two values: the item's **MRP** (the price you expect to sell at) and its **unit cost** (the **Unit Price** you pay the supplier). The larger the gap between the MRP and the unit cost, the higher the margin.

| MRP | Unit Cost | Margin % |
| --- | --------- | -------- |
| 720 | 720 | 0 (cost equals MRP, so there is no margin) |

Use the margin to check that the price on the supplier's invoice leaves you a healthy profit before you save the GRN.

### Payment Tab

Use the **Payment** tab to record how you pay the supplier for the GRN. You can add **as many payment lines as you need**, so one GRN can be settled with a mix of payment types, for example part cash and part cheque.

<Image src="/images/grn_payment.png" alt="GRN Payment tab" zoom={true} />

1. Open the **Payment** tab.
2. Click **Add Row**.
3. Fill in the payment details.
4. Repeat for each payment made.

| Field | Description |
| ----- | ----------- |
| **Amount** | The amount paid in this payment line |
| **Payment Type** | How you paid, for example `Cash` |
| **Check No** | The cheque number. This applies **only to the Cheque payment type** |
| **Bank** | The bank the cheque or transfer is drawn on |
| **Action** | Click the delete icon to remove the payment line |

Payment types are the same as on a Sales Invoice: Cash, Credit (credit card), Bank Transfer and Cheque. See [Payment Types](/sales/sales_entry/sales_invoice#payment-types).

**Post to Purchase Payment**

Once the payment lines are entered, click **Post to Purchase Payment**. The payments are then posted to the **Purchase Payments** window, where they are recorded against the supplier. See [Purchase Payments](/purchase/purchase_payments).

### Buttons

| Button | Description |
| ------ | ----------- |
| **Upload Products** | Add items from a CSV file |
| **Convert to Purchase Receipt** | Converts the **entire GRN** into a purchase payment for the supplier in one step. See [Purchase Payments](/purchase/purchase_payments) |
| **Convert to PR** | Creates a [Purchase Return](/purchase/purchase_return) for the goods |
| **Convert to Payable Invoice** | Creates a payable invoice, which posts an entry in the Accounts module |
| **Quick Add Items** | Add items quickly as rows |
| **Cancel** | Discard changes and go back |
| **Update** | Save the changes |

> **Convert to Purchase Receipt** pays the whole GRN. To pay only part of it, or to pay with several payment types, use the [Payment tab](#payment-tab) and **Post to Purchase Payment**.

## Printing

The buttons at the top right of the GRN are:

| Button | Description |
| ------ | ----------- |
| **Back** | Return to the GRN list |
| **Print Barcode** | Print barcodes for the received items. See [Barcode Printing](/product/barcode_printing/overview) |
| **Print** | Print the GRN |
| **Export** | Export the GRN |

Printing works the same way on every document. See [Saving and Printing](/sales/sales_entry/sales_invoice#saving-and-printing).

> Print templates are **fully customizable**. Contact support if you want a different design.
