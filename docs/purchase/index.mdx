# Purchase Management

Buy goods from suppliers, receive them into stock, and pay for them.

| Page | Purpose |
| ---- | ------- |
| [Purchase Order](/purchase/purchase_order) | Create purchase orders to order goods from suppliers. |
| [Goods Received Note](/purchase/grn) | Record goods received from a supplier (GRN). |
| [Purchase Return](/purchase/purchase_return) | Return goods to a supplier. |
| [Material Issue](/purchase/material_issue) | Issue materials from stock for use in production or other purposes. |
| [Production](/purchase/production) | Record production of finished items from materials. |
| [Production Planner](/purchase/production_planner) | Plan production requirements. |
| [Supplier Agreements](/purchase/supplier_agreements) | Set up agreed terms and prices with suppliers. |
| [Purchase Payments](/purchase/purchase_payments) | Record payments made to suppliers. |
| [Purchase Reports](/purchase/reports) | View purchase reports. |
