# POS Sales

The **POS Sales** screen shows the sales that come from your point-of-sale machines, **SmartPOS 7** and **RestPOS 7**. You can review each day's sales, drill into the items sold, and print or export them.

---

## How POS Sales Reach Cloud ERP

POS sales appear in Cloud ERP **after End of Day (EOD) is completed** on the POS.

1. Complete **End of Day** on SmartPOS 7 or RestPOS 7.
2. The day's sales are synced to Cloud ERP.
3. A record for that day appears in **POS Sales**.

Each EOD sync covers **one day**, so there is ideally **one record per day** for each location.

> If a day's sales are missing, check that EOD was completed on the POS for that day.

## POS Sales List

Go to **Sales** → **Sales Entry** → **POS Sales**.

<Image src="/images/pos_sales_list.png" alt="POS Sales List" zoom={true} />

### Search and export

| Control | Description |
| ------- | ----------- |
| **Select Column** | Choose the column you want to search in |
| **Search by** | Type the value to search for in the selected column |
| **Export to Excel** | Download the list as an Excel file |

You can sort the list by clicking a column heading, and move between pages with the page controls at the bottom.

### Columns

| Column | Description |
| ------ | ----------- |
| **EOD Serial** | The serial number of the End of Day that created this record |
| **Sales Date** | The date the sales were made |
| **Processed Date & Time** | When the EOD was processed and synced |
| **Location** | The location the sales belong to |
| **Total Sales Amount** | Total sales for the day |
| **Total Tax Amount** | Total tax for the day |
| **Total Discount Amount** | Total discount given during the day |
| **Created By** | The user who created the record |
| **Updated By** | The user who last updated the record |
| **View** | Click the **eye icon** to open the record and see more details |

## View a POS Sales Record

Click the **eye icon** on any row to see the full details of that day.

<Image src="/images/pos_sales_view.png" alt="POS Sales Record" zoom={true} />

### Header

| Field | Description |
| ----- | ----------- |
| **EOD Serial** | The EOD serial number. Cannot be edited. |
| **Sales Date** | The date of the sales |
| **Processed Date & Time** | When the EOD was processed. Cannot be edited. |
| **Location** | The location of the sales. Cannot be edited. |
| **Sub Location** | The sub location, if one applies. Cannot be edited. |

The totals bar shows **Total Sales Amount**, **Total Tax Amount**, **Total Discount Amount** and **Total Net Sales Amount** for the day.

### Tabs

The record has three tabs: **Sales Items**, **More Info** and **Recipe**.

#### Sales Items

Lists every item sold during the day.

| Column | Description |
| ------ | ----------- |
| **Line Number** | Line number of the item |
| **Code** | Product code |
| **Description** | Name of the product |
| **Pack Id** | The pack or unit sold, for example `PCS` |
| **Product Type** | The type of product |
| **Quantity** | Total quantity sold |
| **Price** | Selling price per unit |
| **Cost** | Cost per unit |
| **Total Amount** | Amount before tax |
| **Tax Amount** | Tax on the line |
| **Net Amount** | Final amount for the line |
| **Profit** | Profit on the line |
| **Profit Margin%** | Profit as a percentage |

Click **Export to Excel** to download the items.

## Printing

Click **Print** on the record to open the **POS Print Preview**.

<Image src="/images/pos_sales_print.png" alt="POS Print Preview" zoom={true} />

The preview shows your company details, the **Sales Date** and **EOD Serial No**, and the item list with quantity, unit price, tax, total, cost, profit and profit margin.

| Button | Description |
| ------ | ----------- |
| **Print** | Print the POS sales report |
| **Download PDF** | Download the report as a PDF |
| **Download Excel** | Download the report as an Excel file |
| **Close** | Close the preview |

The record also has **Print Barcode** and **Back** buttons. Printing works the same way as on a Sales Invoice. See [Saving and Printing](/sales/sales_entry/sales_invoice#saving-and-printing).

> Print templates are **fully customizable** to match each business and each customer's design.

---

## Important Notes

> POS Sales data appears only after EOD is done on SmartPOS 7 or RestPOS 7.

> There is one record per EOD, which means one record for each day.

> The **Recipe** tab is useful for restaurants, to see how much material was consumed by the items sold.
