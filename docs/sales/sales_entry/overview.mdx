# Sales Entry

**Sales Entry** is the main tab of the **Sales** module. It contains every screen used to record and review sales transactions in Cloud ERP.

---

## Sub Menus

| Menu | Purpose |
| ---- | ------- |
| [POS Sales](/sales/sales_entry/pos_sales) | View sales posted from SmartPOS 7 and RestPOS 7 after End of Day |
| [Sales Order](/sales/sales_entry/sales_order) | Record customer orders |
| [Sales Invoice](/sales/sales_entry/sales_invoice) | Create sales invoices |
| [Proforma Invoice](/sales/sales_entry/proforma_invoice) | Create proforma invoices |
| [Sales Return](/sales/sales_entry/sales_return) | Record returned goods |
| [Invoice Receipt](/sales/sales_entry/invoice_receipt) | Record payments received against invoices |
| [Quotation](/sales/sales_entry/quotation) | Create quotations for customers |
| [Reports](/sales/sales_entry/reports) | Sales reports |
