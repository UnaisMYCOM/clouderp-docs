# Customer

The **Customer** tab is where you create and manage customers in Cloud ERP.

Customers created here can be used for both **wholesale** and **retail** invoices.

---

## Customer Types

| Type | Description |
| ---- | ----------- |
| **Normal** | Standard customer, no credit account |
| **Credit – Prepaid** | Credit customer who pays in advance |
| **Credit – Postpaid** | Credit customer who is billed and pays later |
